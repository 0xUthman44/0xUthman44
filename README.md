## About Me

I'm Uthman, a SOC analyst building toward a detection engineering role, focused on **defensive security, log analysis, and incident investigation**. My work is documented as hands-on lab projects: attack simulations run against a purpose-built environment, the telemetry they generate, and the SOC-style investigations used to detect and analyze that activity.

Every project here is built to mirror the workflow of a working SOC: simulated attacker activity, telemetry, detection, threat hunting, analyst assessment, MITRE ATT&CK mapping, and defensive recommendations. These are lab environments, and where a project's scope is limited, its README says so.

**Certifications:** CompTIA Security+
